# チェックリスト (Checklist Kanban Board)

業務上の定期タスク・提出物を視覚的かつ直感的に管理できる、単一ファイル構成のローカル完結型カンバンボードアプリケーションです。  
外部サーバーや外部ライブラリへの依存が一切なく、ブラウザ単体でセキュアかつ高速に動作します。

---

## 🌟 主な機能

### 1. 4列カンバンビュー
- **日次 / 週次 / 月次 / 提出済み** の4列構成。
- カードをクリックすると、チェックマーク表示のアニメーション（約280ms）を経て自動的に「提出済み」列へスムーズに移動します。
- 「提出済み」列のカードを再度クリックすると、元の列の元の位置へ自動的に復帰します。

### 2. タスクの自由な追加・削除
- **新規タスク作成**:
  - 各列（日次・週次・月次）のヘッダーにある「**＋**」ボタンをクリックすると、列の先頭にインライン入力フォームが表示されます。
  - タスク名（必須・最大100文字）および締切（任意・最大50文字）を入力して即座に追加可能です（`Enter` キーまたは「追加する」ボタン）。
- **タスク削除**:
  - 各カードにカーソルを合わせると右上に削除ボタン（**×**）が表示されます。
  - デフォルトタスク・カスタムタスクを問わず、不要になったタスクを削除できます（削除状態はブラウザに永続保存されます）。

### 3. 直感的なドラッグ＆ドロップ並び替え
- カード左端のドラッグハンドル（`⋮⋮`）またはカード本体を掴んで、列内で直感的に順序を入れ替えることができます。
- **オートスクロール機能**:
  - カードをドラッグしながら画面上端または下端に近づけると、画面が自動的に滑らかにスクロールし、タスクが多い場合でもスムーズに最上部・最下部へ移動できます。
- **キーボード対応**:
  - カード選択時に `Alt + ↑` / `Alt + ↓` キーで1ステップずつ上下に並び替え可能です。

### 4. インライン編集（Click-to-Edit）
- **タスク名編集**:
  - タスク名をクリックするとその場で入力ボックスに切り替わり、名称を直接編集できます（最大100文字）。
- **締切編集**:
  - 締切バッジをクリックすると入力ボックスに切り替わり、締切日時（例: 「毎日」「13時迄」「月末〆」）を直接編集できます（最大50文字）。
  - 締切未設定のカードには「`+ 締切設定`」が表示され、いつでも追加できます。
- `Enter` キーまたはフォーカスアウト（`blur`）で確定保存、`Escape` キーでキャンセルします。

### 5. メモ機能
- 各カード下部のメモ欄に提出日時、進捗、注意事項などを入力できます（最大200文字）。
- 入力内容は即時自動保存されます。

### 6. クリア＆初期値リセット機能
- **クリア（提出済み列ヘッダー）**:
  - 「提出済み」列にあるタスクのチェック状態を一括解除し、すべてのタスクを元の未完了列に戻します（追加したタスクやメモなどの定義自体は消去されません）。
- **初期化（画面右上ヘッダー）**:
  - 追加したタスク、削除状態、編集したタスク名・締切、並び順をすべて初期化し、初期デフォルト状態（全16項目）へ一括復元します（誤操作防止の確認ダイアログ付き）。

## 🔒 セキュリティ＆アーキテクチャ

本アプリケーションは、業務端末やセキュアな閉域環境での利用を想定し、徹底したセキュリティ対策と品質設計を行っています。

- **ゼロ外部依存（Zero External Dependencies）**:
  - CDN、外部スクリプト、Webフォント、外部スタイルシートを一切使用せず、単一HTMLファイル内で完全に完結。
- **XSS（クロスサイトスクリプティング）完全防御**:
  - `innerHTML`、`outerHTML`、`document.write`、`eval`、文字列評価を伴うタイマー関数は一切不使用。
  - すべての動的テキスト描画は `textContent`（`safeText` ユーティリティ）を介して安全に出力されます。
- **厳格な Content Security Policy (CSP)**:
  - `connect-src 'none'; object-src 'none'; default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline';`
  - 外部通信やデータ持ち出し、不正オブジェクト埋め込みをブラウザレベルで完全に遮断しています。
- **LocalStorage 堅牢設計**:
  - 保存データの復元処理に `Object.create(null)` を採用し、プロトタイプ汚染を防止。
  - 型バリデーション（`typeof === 'string'`）、最大長バリデーションを徹底し、破損データや不正データにも安全に対応します。

## 🚀 使い方

1. 本リポジトリの [checklist.html](checklist.html) をダウンロードまたはクローンします。
2. お使いの Web ブラウザ（Google Chrome、Microsoft Edge、Firefox 等）で直接ダブルクリックして開くだけで使用可能です。
   - Web サーバーの起動やインストール作業は一切不要です。
   - オフライン環境でも完全に動作します。
