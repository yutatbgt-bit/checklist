# チェックリスト (Checklist Kanban Board)

業務上の定期タスク・提出物を視覚的かつ直感的に管理できる、単一ファイル構成のローカル完結型カンバンボードアプリケーションです。外部サーバーや外部ライブラリへの依存が一切なく、ブラウザ単体でセキュアかつ高速に動作します。

---

## 🌟 主な機能

### 1. 4列カンバンビュー
- **日次 / 週次提出 / 月次提出 / 提出済み** の4列構成。
- カードをクリックすると、チェックマーク表示のアニメーションを経て自動的に「提出済み」列へ移動します。
- 「提出済み」列のカードを再度クリックすると、元の列の元の位置へ復帰します。

### 2. タスクの自由な追加・削除
- **新規タスク作成**:
  - 各列（日次・週次・月次）のヘッダーにある「**＋**」ボタンをクリックすると、列の先頭にインライン入力フォームが表示されます。
  - タスク名（必須）および締切（任意）を入力して即座に追加可能です（`Enter` キーまたは「追加する」ボタン）。
- **タスク削除**:
  - 各カードにカーソルを合わせると右上に削除ボタン（**×**）が表示されます。
  - デフォルトタスク・カスタムタスクを問わず、不要になったタスクを削除できます。

### 3. ドラッグ＆ドロップによる自由な並び替え
- カード左端のドラッグハンドル（`⋮⋮`）またはカード本体を掴んで、列内で直感的に順序を入れ替えることができます。
- **キーボード対応**: カード選択時に `Alt + ↑` / `Alt + ↓` キーで1ステップずつ上下に並び替え可能です。
- **オートスクロール機能**:
  - タスクを一番下から一番上へ運ぶ際、ポインターが画面上端（または下端）に到達すると画面が自動的に滑らかにスクロールし、長いリストでも一気に最上部・最下部へ移動できます。

### 4. インライン編集（Click-to-Edit）
- **タスク名編集**:
  - タスク名をクリックするとその場で入力ボックスに切り替わり、名称を直接編集できます。
- **締切編集**:
  - 締切バッジをクリックすると入力ボックスに切り替わり、締切日時（例: 「毎日」「13時迄」「月末〆」）を直接編集できます。
  - 締切未設定のカードには「`+ 締切設定`」が表示され、いつでも追加できます。
- `Enter` キーまたはフォーカスアウト（`blur`）で確定保存、`Escape` キーでキャンセルします。

### 5. メモ機能
- 各カード下部のメモ欄に提出日時、進捗、注意事項などを入力できます（最大200文字）。
- 入力内容は即時自動保存されます。

### 6. クリア＆初期値リセット機能
- **クリア（提出済み列ヘッダー）**:
  - 「提出済み」列にあるタスクのチェック状態を一括解除し、すべてのタスクを未完了状態に戻します（タスク定義自体は消去されません）。
- **リセット（画面右上ヘッダー）**:
  - 追加したタスク、削除状態、編集したタスク名・締切、並び順をすべて初期化し、初期デフォルト状態（全16項目）へ一括復元します。

## 🔒 セキュリティ＆アーキテクチャ

本アプリケーションは、業務端末やセキュアな閉域環境での利用を想定し、厳格なセキュリティ対策を講じています。

- **ゼロ外部依存**:
  - CDN、外部スクリプト、Webフォント、外部スタイルシートを一切使用せず、単一HTMLファイル内で完結。
- **XSS（クロスサイトスクリプティング）完全防御**:
  - `innerHTML`、`outerHTML`、`document.write`、`eval`、文字列評価を伴うタイマー関数は一切不使用。
  - すべての動的テキスト描画は `textContent`（`safeText` 関数）でサニタイズされます。
- **厳格な Content Security Policy (CSP)**:
  - `connect-src 'none'; object-src 'none'; default-src 'self';` により、悪意ある外部通信やデータ持ち出しをブラウザレベルで遮断。
- **LocalStorage プロトタイプ汚染対策**:
  - 保存データの復元処理に `Object.create(null)` を採用し、オブジェクト構造と型バリデーション（`typeof === 'string'`、文字長制限）を徹底。

## 🚀 使い方

1. 本リポジトリの [チェックリスト.html](チェックリスト.html) をダウンロードまたはクローンします。
2. お使いの Web ブラウザ（Google Chrome、Microsoft Edge、Firefox 等）で直接ダブルクリックして開くだけで使用可能です。
   - Web サーバーの起動やインストール作業は一切不要です。
